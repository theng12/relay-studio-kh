# Open work — relay-studio-kh

Open tasks and known defects for this repository only; updated in the same commit whenever work starts, changes, or closes. Shipped work lives in `CHANGELOG.md`.

- [ ] **The signed gate says two checks fail, and both are older than 0.3.41** — `TESTMODE` fails because Relay has no port-served headless entry (its acceptance is the Node/render gate plus a labelled desktop-preview fixture), and `ENTITLEMENT` fails because `Sparkle.framework` is embedded with no entitlements file. The second is inert today only because the app is not signed with the hardened runtime; it would bite the day it is. **Next:** add a headless test entry the scanner accepts, and resolve the entitlements question together with the hardened-runtime decision.
- [ ] **Sparkle's own update has never been exercised** — the feed, the key, the framework and the hold are all proven, and a hidden launch shows the check running, but no installed Relay has been watched taking a newer version. **Next:** on a Mac holding 0.3.40, let it take 0.3.41 and record the version readback before and after.
- [ ] **Busy-state and long-run memory are unmeasured** — the idle footprint is proven flat over ten minutes, but there is no figure for Relay during active work or after a long run of accounts. **Next:** measure both with a throwaway data dir and real accounts, and record them on the next receipt.
- [ ] **Start at Login is unexercised where it actually registers** — the app asks the system to register a login item and reports when the system is holding the change for approval, but no logout/login cycle has ever been run against it here. **Next:** log out and back in on a Mac where the registration succeeds and confirm Relay returns.
- [ ] **The installed 0.3.41 was not traced to an installer** — the app in `/Applications` is 0.3.41 with byte-for-byte the published DMG's contents, but no updater or launcher log line records who put it there, so the automatic install path is unproven even though the installed bytes are right. **Next:** on the next release, capture the updater's own log line for Relay and confirm it names the version it installed.
